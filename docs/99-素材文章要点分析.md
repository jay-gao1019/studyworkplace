# 99 · 素材文章深度分析

> 来源：微信公众号"AI没幻觉"《用workbuddy手搓一个小学生学习工作台》，2026-10-24，广东。本文档为 SSD 阶段一的输入材料拆解，供追溯设计出处。

## 1. 产品定位一句话

家长用 AI 工具（workbuddy）手搓的**单 HTML 文件**小学生学习工作台：双击浏览器即用，无后端、无依赖、无账号、数据全在本地。

## 2. 痛点与主张

作者原话概括每天面对三件事：**打卡靠吼、进度靠记、错题靠猜**。对市面 App 的不满：开屏广告、强制注册、不能定制、要会员，且都在堆内容；而家长真正要的只是——**今天该做什么、做到了没有、哪里还不会**。

## 3. 功能结构拆解（一文件五区域）

顶部状态栏（年级/姓名/等级/连续打卡/剩余金币/累计金币）· 年级切换（1–6 年级×上下学期+孩子档案）· 工具栏（每日打卡+20/后台配置/导出/导入）· 左侧导航（学习台/语文/数学/英语/知识体系）· 主区（金币柱状图 日/月/年 + 今日计划清单）。

## 4. 五大模块机制

**① 打卡+金币（解决"愿不愿意学"）**：任务分赚币（阅读30分钟+5、口算+5、户外20分钟+5、练字10分钟+5）与扣币（未按时作业−10、超时电子设备−10）；全部后台可改（名称/金额/适用年级）。金币有账本（剩余/累计/日年月统计）；等级五级（小嫩芽→绿幼苗→向阳花→知识树→小学霸）；连续打卡断则归零。商店奖励明码标价（动画片60/游戏30分钟120/买书200/周末游玩300/点菜单80/晚睡10分钟100）。**核心取舍：工具只做记账，不做兑现；奖励孩子自己提、家长定预算边界**，防激励退化为讨价还价。

**② 教材目录**：三科按人教版组织，切年级学期自动变；语文按单元/识字/拼音/阅读；数学按校内单元+额外奥数模块；英语按 Unit+四分组（话题词汇/核心句型/语音/交际与文化）。条目可勾选打卡+5金币，进度折算为科目百分比。**意义：把"今天学语文"拆成"把这一课生字过一遍"这类可执行可量化动作。**

**③ 知识体系**：四层树——年级→册/模块→单元/主题→知识点（叶子挂真题+解析，题库来源为作者从 ima 知识库整理的几十个共享题库）。页顶统计（末级知识点数/节点总数/已答题/精通+掌握占比）+ 掌握度六档筛选。**架构精髓：学习、练习、诊断共用同一棵树**——任务从树生成、答题记录挂树上、掌握度按叶子统计。

**④ 掌握度分级**：正确率 ≥90% 精通(绿)、80–90% 掌握(蓝)、30–80% 部分掌握(黄)、<30% 未掌握(红)、未答(灰)。"刷了多少题"变成"哪些知识点变红了"，红点=明日专项攻关清单。**洞察：家长需要的不是题量，而是"病灶"位置。**

**⑤ 多孩子+导入导出**：档案完全隔离（余额/累计/年级/学期/计划互不影响）；数据存浏览器本地；导出=全量备份（后台配置+答题记录与掌握度一次导出），新机导入即完整恢复。

## 5. 效果与局限

作者反馈：孩子每天用，积极性提升明显。局限（也是我们的改进机会）：单 HTML 无工程化结构、内容内置但不可批量扩展、无生活维度管理、移动端不友好、无 PIN 家长门。

## 6. 借鉴 → 本项目落点映射

| 原文做法 | 本项目落点 | 改进 |
|---|---|---|
| 单 HTML 零依赖 | Vue3+Vite 工程化，构建产物仍纯静态离线 | 可持续扩展、可测试 |
| 金币账本+五级等级+连续打卡 | M1/M2 全量继承，默认值同原文 | 不可变流水+可审计冲正 |
| 只做记账不做兑现 | M3 兑换 pending/redeemed 状态机 | 家长确认闭环 |
| 人教版三科目录+奥数 | M4 + seed 内容规格（≥600 条目） | 1–6 全册结构化 |
| 学练诊同一棵树 | M5 + 数据模型全局共享树 | quizSetHash 防改题污染 |
| 掌握度五级 | M5.5 全量继承（阈值一致） | 色盲形状冗余 |
| 多孩子隔离 | M8 档案分区 | 删除保护+确认词 |
| 导出/导入全量 | M8 版本化 JSON+校验和 | 损坏可诊断、可迁移 |
| （无） | **新增 M6 生活营**：作息/家务/屏幕账户/21天习惯链 | 学习+生活双线督促 |
| （无） | **新增 M7 家长 PIN 门** | 防孩子改规则 |

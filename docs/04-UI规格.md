## 2. 页面清单与线框要点

### P1 学习台（首页 #/desk）

- 上半：**金币柱状图**（切换 日/月/年；双色柱=收入绿/支出红；hover/点按显示数值）。
- 下半：**今日计划清单**——赚币项（大复选框卡片，左图标右名称，勾选后卡片变绿+飘 `+5🪙`）；已扣项以红色小字列于底部"今天被扣了：未按时作业 −10"（不可自勾，M2.4）。
- 右上悬浮卡：连续打卡火焰 + 本周完成率环（学习线/生活线双环，FR-20）。
- **常显进度卡（v2.2）**：语/数/奥/英四进度条（奥数单列，解决"奥数只在顶栏徽标出现"问题），数据取 bootstrap progress。
- **📊 数据统计卡（v2.2，FR-25/M10）**：位于柱状图下方；周/月切换；收支分类迷你条+计划完成率+自测轮数与平均正确率+掌握度六档分布+生活摘要（作息按时/屏幕分钟/习惯次数）；接口失败显示"报表暂不可用"。
- 空态：无任务项时显示"请爸爸妈妈先在后台配置任务"+直达后台按钮。

### P2 教材页（#/cn #/math #/en 共用组件）

- 顶部：科目名 + 该科进度条（如 数学 37%，奥数单列 12%）。
- 主体：单元分组卡片，叶子条目行=`☐ 条目名 …… [知识点 +5🪙]`；行尾"知识点"按钮跳转知识树并定位该叶子（学练诊同树入口，M5.10 关联）。
- **单元标题行（v2.2，FR-24/M4.7）**：每单元标题右侧、条目自测之前，放 [📖 打开电子书] 按钮；书目就绪→大弹层内嵌 `<iframe src="/api/ebook/{subject}/{grade}/{term}/file#page=N">`（N=种子 ebookPage，缺省 1），顶部标注单元名与页码；未就绪→按钮置灰+提示文案。
- 数学页有"校内/奥数"双 Tab；英语页 Unit 手风琴内嵌四分组小标题。
- 已完成条目划线灰化，勾选即时结算。

### P3 知识体系（#/knowledge）

- 顶部统计条：末级知识点数 · 大纲节点总数 · 已答数 · 精通+掌握占比。
- 筛选条：六档胶囊（全部/精通/掌握/部分/未掌握/未答），选中"未掌握"时出现 [🎯开始攻关] 按钮。
- 左树右答双栏：树节点行=展开箭头+标题+掌握度色点（绿蓝黄红灰）+"待重测"叹号角标；点击叶子右侧加载自测面板。
- 自测面板：题号进度（2/5）→ 题干 → 单选radio大卡片/填空输入框 → [提交] → 即时结果条（✓答对/✗正确答案是X）+解析折叠区 → [下一题] → 整轮完成显示本轮正确率与新掌握度徽章（升级时撒花动效）。

### P4 生活营（#/life，本项目新增）

- 四宫格分区：**作息**（早晚两个大按钮，显示目标时间窗口与按时状态）· **家务**（任务池卡片同 P1 样式）· **屏幕**（圆形进度计时器：今日额度已用 25/40min；[开始计时]/[暂停/结束]；超时态变红+锁定文案）· **习惯**（21 格链，完成格填色，7/14/21 里程碑徽章位）。
- 底部：本周双线完成率（学习 vs 生活两列迷你柱状）。

### P5 兑换商店（#/shop）

- 商品卡片网格：图标+名称+价格；余额不足卡片置灰并标"还差 X🪙"；兑换需二次确认弹层（"和爸爸妈妈约好了吗？确认兑换？"）。
- 我的兑换列表：状态徽标（待兑现·黄/已兑现·绿/已撤销·灰）。

### P6 后台配置（#/admin，PIN 门）

- PIN 输入屏：4 位数字键盘（儿童不宜窥视，输入打点显示）。
- Tab 页：**用户管理**（档案卡列表+新建/编辑/删除）· **每日计划**（学习/生活任务项表格：名称/金额/年级范围/启用；**v2.2**：任务弹窗图标=内置表情选择器+手输、年级范围=1–6 复选框+"全部"开关；页底部新增**🧾 数据修正**区——近 50 条流水表（时间/类型/金额/原因），行尾 [✏️修正] 弹层输入新金额+原因，提交后成对生成"冲正+补录"并在表上即时刷新，兑换类流水行显示"请用商店撤销"）· **商店** · **生活设置**（作息窗口/屏幕额度/罚则/习惯管理）· **数据与题库**（题库 JSON 导入·等级阈值·危险区）。
- 危险区红色区块，确认词输入框（M8.4）。

### P7 导出/导入

- 导出：点击即下载 + toast 成功（含文件名）。
- 导入：文件选择 → 校验中进度 → 摘要预览卡（档案列表、流水条数、备份日期、与当前差异）→ [确认覆盖] / [取消]；失败显示可读原因。

## 3. 关键交互流（时序）

**今日打卡流**：打开(默认档案默认页) → 看今日清单 → 勾第一项 → 即时结算+飘字+余额跳动 → …… → 点签到 → 火焰 +1 → 离开。全程 ≤3 次点击完成一项。

**攻关流（家长最想用的）**：知识体系 → 筛"未掌握" → 点[开始攻关] → 依次打开红点叶子自测 → 全对 → 变绿 → 筛选条红点数字实时减少 → 攻关完toast"今天的红点清零啦！"。

**兑换流**：商店 → 选品 → 确认弹层 → 扣币+pending → 家长后台"商店"Tab → 标已兑现 → 孩子端徽标变绿。

## 4. 视觉规范（儿童友好 Design Tokens）

| Token | 值 | 用途 |
|---|---|---|
| `--font-body` | 16–18px（正文）/22px（题干） | NFR-05 大字号 |
| `--radius` | 16px（卡片）/999px（胶囊） | 圆润无锐角 |
| `--c-primary` | #FF8A3D 橙 | 主行动色（温暖不刺眼） |
| `--c-income` | #34C759 绿 / `--c-expense` #FF3B30 红 | 金币语义 |
| `--c-mastery-*` | 精通#2FBF57 掌握#3B82F6 部分#F5B301 未掌握#E5484D 未答#9CA3AF | 与 M5.5 一致；**同时配形状**：精通绿圆✓/掌握蓝实心圆●/部分黄三角▲/未掌握红菱✕/未答空心圆○/待重测橙方块（色盲冗余，NFR-06，v2.1 落地定稿） |
| `--c-bg` | #FFF9F0 米白 | 低视觉疲劳 |
| 主题插画 | 植物成长五阶段对应五级（小嫩芽→小学霸） | 顶栏徽章+升级庆祝页 |

动效规范：飘字 800ms、卡片勾选弹性 200ms、升级撒花 1.5s（可全局关闭）；不使用闪烁/自动播放音频。

文案规范：负反馈对事不对人（"还差 20 金币哦"而非"你不够"）；全部使用中文口语化短句，一年级可读（配合图标）。

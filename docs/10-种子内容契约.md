# 10 · 种子内容契约（Design）

> 教材目录与知识树/样例题数据文件规范 ｜ 供数据生成与 seed-load 共同遵循 ｜ 版本 v1.3（全学段 1–6 保留；**4–6 年级为校内知识重点学段**，v2.3 起该学段每知识点 15 题，对应需求 FR-30）

## 1. 文件清单

| 文件（`src/main/resources/seed/`，随 jar 打包、经 `/seed/*.json` 静态伺服） | 内容 | 负责里程碑 |
|---|---|---|
| `textbook-cn.json` | 语文 1–6 年级上下册目录树 | T3.3 |
| `textbook-math.json` | 数学 1–6 全册（含奥数平行分支） | T3.4 |
| `textbook-en.json` | 英语 1–6 全册（Unit 制） | T3.5 |
| `knowledge-cn.json` `knowledge-math.json` `knowledge-en.json` | 知识体系树 + 样题（**1–6 全学段，terms 12 项/科**；math 含校内+奥数双分支；**4–6 年级为内容深度与校对重点**） | T3.6 |

## 2. ID 命名（全局唯一，禁止变更已发布 ID）

```
教材叶子:  tb-{cny|mat|eng}{grade}{a|b}-l{NN}      例 tb-cny1a-l01   (a=上册 b=下册)
教材分组:  tb-{...}-g{NN}
知识模块:  kn-{...}{grade}{a|b}-m{NN}
知识单元:  kn-{...}-u{NN}
知识点叶:  kn-{...}-f{NN}
题目:      qz-{leafId}-{n}                          例 qz-kn-mat4a-f02-1
```

## 3. 教材文件结构（textbook-*.json）

```jsonc
{
  "subject": "cn|math|en",
  "terms": [                       // 12 项：grade1a … grade6b
    { "grade": 1, "term": "上",
      "modules": [                 // 语文:单元(含 我上学了/识字/汉语拼音/阅读 性质); 数学:校内单元1..n; 英语:Unit1..n
        { "id": "tb-cny1a-g01", "title": "识字（一）", "branch": "校内",   // branch 仅数学用："校内"|"奥数"
          "leaves": [ { "id": "tb-cny1a-l01", "title": "1 天地人" },
                      { "id": "tb-cny1a-l02", "title": "2 金木水火土" } ] } ] }
  ]
}
```

要求：**每个(科目×年级×学期)组合 ≥10 个叶子、≥4 个分组**；语文含"组5 单元（汉语拼音）"类分组；英语模块下可选 `"groups"`（话题词汇/核心句型/语音/交际与文化）再挂叶子；数学 `branch:"奥数"` 每学期 ≥3 专题叶子。标题带课序数字（如"3 古诗三首"）。

**v2.2 可选字段**：教材分组可加 `"ebookPage": 12`（正整数）——该单元在配套人教 PDF（`data/ebooks/<subject>-<年级><上|下>.pdf`，FR-24/M4.7）中的起始页码；缺省则电子书弹层从第 1 页打开。种子装载忽略未知字段，旧 seed 无需改动。

## 4. 知识文件结构（knowledge-*.json）

```jsonc
{
  "subject": "math",
  "terms": [
    { "grade": 4, "term": "上", "branch": "校内",           // 数学双分支；其他科可省
      "modules": [
        { "id": "kn-mat4a-m01", "title": "数与代数",
          "units": [ { "id": "kn-mat4a-u01", "title": "大数的认识",
            "leaves": [ { "id": "kn-mat4a-f01", "title": "亿以内数的读写",
              "quizzes": [
                { "id": "qz-kn-mat4a-f01-1", "type": "single",
                  "stem": "下面哪个数的读法需要读出两个零？",
                  "options": [ {"id":"A","text":"1000100"}, {"id":"B","text":"1010100"}, {"id":"C","text":"1001100"}, {"id":"D","text":"1101000"} ],
                  "answer": "B",
                  "explanation": "1010100 读作：一百零一万零一百，读出两个零。" },
                { "id": "qz-kn-mat4a-f01-2", "type": "blank",
                  "stem": "三百零五万零四十 写作：______",
                  "answer": "3050040", "answerAccepts": ["3050040"],
                  "explanation": "万级是305，个级是0040。" }
              ] } ] } ] }
      ] }
  ]
}
```

要求（v1.2 范围）：知识文件 terms 覆盖 grade 1–6 × 上/下 共 12 项；每(科目×年级×学期) ≥6 个知识点叶子、每叶 ≥2 题（**单选与填空混合，至少各 1**）；**4–6 年级每个知识点 =15 题**（v2.3 重点学段加密度：数学/奥数含计算题由程序计算答案保证可答，语文/英语基于内置语料模板；生成器 `tools/QuizExpander` 维护此下限，SeedContractTest 断言 4–6 年级 150 叶全部恰 15 题）。`explanation` 必须说理，不得只复述答案。填空 `answer` 为规范化后可精确匹配的形式（去空格、半角数字）；多可接受答案全部列入 `answerAccepts`。**v2.3 起 15 题=自测一整轮**（M5.4 全量作答），家长导入自定义题可覆盖内置生成题（origin=custom 优先内置 builtin）。

## 5. 内容质量红线

题目答案必须正确（生成后逐题自查）；不抓取、不复制受版权保护的教辅原文；教材目录采用公开课程结构，允许与最新版个别条目存在出入（README 注明"目录为参考结构，可在后台调整导入"）；语文题面向理解运用（拼音、组词、近反义词、古诗理解），不收录课文原文段落。

## 6. 校验（JUnit，无 Python/Node）

`src/test/java/com/studdy/SeedContractTest.java`：文件存在性 → JSON 可解析（Jackson）→ 结构约束（§3/§4 必需键、ID 正则与全局唯一、数量下限、题目 options=4、answer 属于 options 或 answerAccepts）→ 打印统计报表。`mvn test` 非零退出即失败。

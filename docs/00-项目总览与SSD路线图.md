# 小学生学习督促平台 · 项目总览与 SSD 路线图

> 项目代号：**StudyWorkplace**（小学生学习工作台）
> 文档版本：v2.0 ｜ 日期：2026-10-25 ｜ 状态：架构 v2.0（Spring Boot + MySQL）文档重修订完成；实现进行中（沿革 v1.0 Vue → v1.1 原生ESM → v2.0 服务端，见 docs/02 §1.1）

## 1. 项目背景

本项目参考公开文章《用workbuddy手搓一个小学生学习工作台》（公众号"AI没幻觉"，2026-10-24）的产品理念，为小学生家庭构建一个**有计划地督促学习与生活**的平台上架级应用。

原文核心洞察（本项目全部继承）：

- 小学生家庭每天面对三件事：**打卡靠吼、进度靠记、错题靠猜**。
- 市面学习 App 的通病：广告、强制注册、不能定制、收费会员；且都在做"内容越多越好"，而家长真正要的只有一句话——**今天该做什么、做到了没有、哪里还不会**。
- 关键设计取舍：
  - **工具只做记账，不做兑现**——金币不能自动换东西，规则由家长与孩子事先约定，避免激励退化为"用钱买学习"和讨价还价。
  - **学习、练习、诊断共用同一棵树**——打卡任务、答题记录、掌握度统计都挂在同一棵知识体系树上，不需要维护三份互相对不上的清单。
  - **家长需要的不是题量，而是"病灶"位置**——用掌握度分级让"哪里不会"可视化，红点即第二天专项攻关清单。

与原文的区别：本项目按用户要求采用 **Spring Boot（Java 17）+ MySQL 后端 + 原生 HTML/CSS/JS（ES Modules，无 Node 无构建）前端**的服务端架构：数据存于家中服务器的 MySQL（多设备一致、换浏览器不丢），业务规则收敛在后端 domain 层，家长 PIN 为服务端真鉴权；内置教材目录与知识树以静态 JSON 随应用分发、可整体替换；并在原文基础上**新增生活管理模块**（作息、家务、电子屏幕时间、习惯养成，学习与生活双线激励）。

## 2. SSD（Spec-Driven Development）范式说明

本项目严格遵循规范驱动开发三阶段流程：

```
阶段一 Specification（做什么/为什么）
   └─ docs/01-需求分析.md            —— 用户故事、功能需求、验收标准
阶段二 Design（怎么做）
   ├─ docs/02-架构设计.md            —— 技术选型（无Node原生ESM）、分层架构、领域模型
   ├─ docs/03-模块微规格.md          —— 每个模块的输入/输出/规则/边界条件
   ├─ docs/04-UI规格.md              —— 页面、信息架构、交互流、视觉规范
   ├─ docs/05-数据模型规格.md        —— 数据契约定义、持久化方案、导入导出格式
   └─ docs/10-种子内容契约.md        —— 教材目录/知识树/样例题数据文件规范
阶段三 Tasks & Implementation（按单执行）
   ├─ docs/06-任务拆解与验收.md      —— 可执行任务清单（含依赖与验收标准）
   └─ docs/feature_list.json         —— 功能状态跟踪表（实现阶段逐项勾验）
```

**执行纪律**：

1. 未经文档化的行为不实现；实现与文档冲突时，先修订文档再继续。
2. 每个任务必须携带可验证的验收标准，完成时按标准自测勾验。
3. `feature_list.json` 是唯一的状态事实来源（pending → in_progress → done）。

## 4. 范围界定

**本期做（v1.0）**

- 多孩子档案（数据完全隔离），1–6 年级、上/下学期
- 每日计划打卡 + 金币账本（赚币/扣币、等级、连续打卡、日/月/年统计图）
- 兑换商店（家长定价、孩子自证兑现，工具只记账）
- 人教版语文/数学/英语教材目录（可勾选打卡、进度折算），1–6 年级全册；数学含奥数平行模块
- 四级知识体系树（年级→册/模块→单元/主题→知识点），知识点挂真题自测；覆盖 1–6 年级三科，**4–6 年级为校内知识重点学段**（内容深度与校对优先；v2.2 澄清：1–3 年级保留）
- 掌握度五级分级（精通/掌握/部分掌握/未掌握/未答）与筛选
- **生活管理模块**：作息（睡眠/起床）、家务劳动、电子屏幕时间、习惯养成打卡（与金币账本打通）
- 后台配置：计划项、商店、生活项目、题库全部可由家长增删改
- 本地服务器持久化（家庭 MySQL，自动建库）+ 全量导出/导入 JSON 备份（跨机迁移）

**本期不做**

- 云端账号、多端实时同步、家校协同
- 自动判分主观题、语音评测、AI 出题
- 内容版权风险的大规模题库内置（预置结构化样例 + 后台导入扩展）
- 移动端原生 App（Web 响应式覆盖平板即可）

## 5. 术语速查

| 术语 | 含义 |
|---|---|
| 档案（Profile） | 一个孩子的独立数据空间（金币、计划、进度、答题记录全部隔离） |
| 知识树（KnowledgeTree） | 教材目录与知识体系共用的四级树结构，是任务、练习、诊断的唯一事实来源 |
| 知识点（Leaf） | 知识树的叶子节点，可挂 0..n 道自测题 |
| 掌握度（Mastery） | 由知识点答题正确率自动折算的五级标签 |
| 账本（Ledger） | 金币的不可变流水记录，余额由流水推导 |
| 兑现（Redeem） | 商店兑换记录；工具只记账，实际兑现在线下由家长完成 |
